⚛️ Konfigurasi Elektron Atom Bohr

Kimia Kelas 10 • Kulit K, L, M, N

📘 Model Atom Bohr: Kulit Elektron

Menurut Teori Atom Bohr, elektron berada dalam suatu lintasan (orbit) tertentu yang disebut kulit elektron, diberi lambang K, L, M, N, dan seterusnya dihitung dari inti atom.

Rumus jumlah elektron maksimum per kulit:

Σ maksimum = 2n²
Nomor Kulit (n)LambangElektron Maksimum (2n²)
1K2
2L8
3M18
4N32

Contoh: kulit ke-3 (M) → 2×3² = 18 elektron.

🔵 Aturan Pengisian Kulit K dan L

Aturan Kulit K

  • Diisi 2 elektron, jika elektron tersedia ≥ 2.
  • Diisi 1 elektron, hanya untuk atom Hidrogen (H).

Aturan Kulit L

  • Diisi 8 elektron, jika elektron tersedia ≥ 8.
  • Diisi sisa elektron, jika elektron tersedia < 8.

Contoh:

₃Li : 2, 1 → K=2, L=1 ₁₂Mg : 2, 8, 2 → K=2, L=8, M=2

🟠 Aturan Pengisian Kulit M dan N

Aturan Kulit M

  • 18 elektron, jika elektron tersedia > 18.
  • 8 elektron, jika 8 ≤ elektron tersedia < 18.
  • Sisa elektron, jika elektron tersedia < 8.

Aturan Kulit N

  • 32 elektron, jika elektron tersedia > 32.
  • 18 elektron, jika 18 ≤ elektron tersedia < 32.
  • 8 elektron, jika 8 ≤ elektron tersedia < 18; sisanya jika < 8.

Contoh:

₁₇Cl : 2, 8, 7 ₂₀Ca : 2, 8, 8, 2 ₃₆Kr : 2, 8, 18, 8 ₃₈Sr : 2, 8, 18, 8, 2 ₄₉In : 2, 8, 18, 18, 8, 3 ₈₁Tl : 2, 8, 18, 32, 18, 3

✅ Empat Hal yang Wajib Diingat

1 Kulit elektron K, L, M, N… dihitung dari inti atom keluar; kapasitas maksimumnya 2n².

2 Kulit K maksimal 2 elektron (istimewa: H hanya 1); Kulit L maksimal 8 elektron.

3 Kulit M maksimal 18, dan kulit N maksimal 32, namun tetap mengikuti aturan sisa elektron terluar.

4 Selamat berlatih! Semoga sukses memahami konfigurasi elektron atom Bohr. 🎉
